# FoodSnap – บันทึกแคลอรี่จากรูปอาหาร

เว็บแอปไฟล์เดียว (`index.html`) ถ่ายรูปอาหาร → AI บน Groq บอกชื่อเมนูและแคลอรี่ → บันทึกลง Local Storage → ดูสรุปแคลอรี่ของวัน

## วิธีใช้
1. เปิดไฟล์ `index.html` ด้วย Chrome / Edge / Safari (ดับเบิลคลิกได้เลย)
2. ไปที่แท็บ **ตั้งค่า** → ใส่ **Groq API Key** (สร้างได้ที่ https://console.groq.com/keys ขึ้นต้นด้วย `gsk_`) → กด *บันทึกการตั้งค่า*
3. กดปุ่ม **กล้อง** ตรงกลางด้านล่าง → ถ่ายรูปหรือเลือกรูปอาหาร
4. รอ AI วิเคราะห์ → ตรวจ/แก้ไขชื่อเมนูและแคลอรี่ → กด **บันทึก**
5. หน้า **วันนี้** จะแสดงแคลอรี่ที่ได้รับ เทียบกับเป้าหมาย และรายการอาหารทั้งหมด

## ฟีเจอร์
- วงแหวนแคลอรี่ของวัน + โปรตีน / คาร์บ / ไขมัน
- ดูย้อนหลังรายวัน และกราฟ 7 วันล่าสุด
- กรอกข้อมูลเองได้ (ไม่ต้องมี API key)
- Export / Import ข้อมูลเป็นไฟล์ JSON
- รองรับ Dark mode อัตโนมัติ

## ข้อควรทราบ
- ข้อมูลและ API Key เก็บใน Local Storage ของเบราว์เซอร์เครื่องนั้นเท่านั้น ถ้าล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่อง ข้อมูลจะไม่ตามไป → ใช้ Export สำรองไว้
- แอปเรียก Groq API (`https://api.groq.com/openai/v1/chat/completions`) โมเดลเริ่มต้น `qwen/qwen3.8-27b` เปลี่ยนได้ในหน้าตั้งค่า แต่ต้องเป็นโมเดลที่รองรับรูปภาพ (ดู https://console.groq.com/docs/vision)
- การใช้งานขึ้นกับโควตา/rate limit และค่าใช้จ่ายตามบัญชี Groq ของคุณ
- ค่าแคลอรี่เป็นการประเมินจากรูป อาจคลาดเคลื่อนจากความจริง
- ใช้บนมือถือ: นำไฟล์ไปวางบนเว็บโฮสต์ (HTTPS) หรือเปิดไฟล์บนมือถือโดยตรง ปุ่ม "ถ่ายรูป" จะเปิดกล้องให้ทันที
